Watchdog x402: security checks your agent pays for

Security checks for Solana and EVM, paid by AI agents per call in USDC over the x402 payment protocol. No account, no API key. Also available as the open source watchdog-mcp MCP server for Claude, Cursor and other MCP clients.

x402 endpoints

  • Solana, POST /agent/program, $0.05: upgrade authority (single key, Squads v4 multisig, DAO, immutable), last deploy, verified build, security.txt.
  • Solana, POST /agent/check, $0.01: RustSec / OSV advisories for a Cargo.lock.
  • Solana, POST /agent/scan, $0.50: full scan of a public Rust / Anchor repo.
  • Solana, POST /agent/watch, $0.90: 30 days of hourly checks with signed webhooks.
  • EVM, POST /agent/contract, $0.05: proxy kind, live implementation, upgrade controller and owner (key, Safe, timelock). Base and Robinhood Chain.
  • EVM, POST /agent/check, $0.01: advisories for a package-lock.json or yarn.lock.
  • EVM, POST /agent/scan, $0.50: full scan of a public Solidity repo.
  • EVM, POST /agent/watch, $0.90: 30 days of hourly checks with signed webhooks.

Agent manuals: Solana, EVM. Summary for LLMs: llms.txt.

Checks, not a certified audit. Open source under the MIT license.
