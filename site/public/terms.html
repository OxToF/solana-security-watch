What Watchdog is

Watchdog runs automated security checks on public code repositories and on-chain programs: who can upgrade a program, known advisories in the exact dependency versions it ships, build hygiene, and known vulnerability classes reported as leads to confirm by reading.

These are checks, not an audit. A report lists what the checks found. It does not certify that code is free of bugs, that a program is safe to use, or that funds placed in it are safe. Findings can be incomplete or wrong. Nothing in a report is financial, investment or legal advice, and you remain responsible for any decision you make with it.
